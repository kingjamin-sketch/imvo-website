# Phase 1 — Mobile & Contrast Notes

This branch applies a narrow follow-up to the accessibility baseline:

- mobile interaction controls use at least 48px tap targets where practical
- project index metadata contrast and size are increased
- footer social controls are 48×48px
- footer supporting/legal text uses higher contrast
- legal links have a 44px minimum interaction height
- team cards stack to one column on very small screens

The approved IMVO visual system is intentionally preserved. This file documents the batch for review and can be removed after merge if preferred.
