# IMVO jelly CTA and testimonial masonry integration

This branch introduces the supplied Jelly Explore Button as an unchanged component, applies it to CTA-style actions while preserving the original anchor or button behavior, and restyles the existing IMVO client testimonials into a dark CSS masonry presentation.

The supplied fintech-style Why Choose Us section is intentionally not included because the live IMVO website already explains its differentiators through Project Intelligence, Studio Principles, Services, and the three About-page pillars. Adding another six-cell benefits block would repeat the same message.

The trusted-logo marquee component is included but not rendered until IMVO-approved client or collaborator logo files are supplied. Unrelated sample logos such as Spotify, Stripe, or GitHub must not be presented as IMVO clients.
