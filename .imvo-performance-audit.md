# IMVO Performance Foundation Audit

## Phase 2 — first safe batch

- Keep the existing system font stack. Adding a custom webfont solely to satisfy the checklist would add network and rendering cost.
- Enable modern AVIF/WebP output through Next.js Image Optimization.
- Reduce eager loading pressure from the homepage hero video while preserving the approved cinematic hero.
- Respect reduced-motion and data-saver preferences with a lightweight static hero fallback.
- Keep existing source assets in place for now; do not mass-delete large originals until all references are audited.

Follow-up batches should audit remaining hard-coded PNG/JPG fallbacks, bundle weight, caching headers, and large source media references.
